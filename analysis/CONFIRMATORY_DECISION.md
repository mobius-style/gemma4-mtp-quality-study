# Confirmatory-expansion decision

Decision date: 2026-08-09. **No-Go for an outcome-triggered larger run inside
this study; Go for a separately frozen replication.**

The completed 200-item paired suite served its intended resource-bounded pilot
purpose: it exposed no scorer failure in the analyzed version, localized the
quality-constrained candidates, and produced intervals that clear the frozen
-5-point margin. It was not prospectively powered for a narrower margin, and
the available public pools do not solve the contamination limitation.

Increasing the sample after observing these estimates without first defining a
new target margin, power calculation, preferably fresher/private tasks, and
independent stopping rule would turn the same-study endpoint into
outcome-dependent sampling. Therefore, this artifact closes as an exploratory
working paper. A larger confirmation is scientifically warranted for stronger
publication claims, but it must be a new, separately frozen replication rather
than an undeclared extension of this dataset.

Minimum replication design:

1. retain OFF and N=6 as the primary pair;
2. define a narrower practical margin and prospective power calculation;
3. add private or newly constructed objective items and Japanese tasks;
4. include a higher-precision target condition to test the Q4_0 interaction;
5. repair NVML before performance collection; and
6. freeze runtime commit, prompts, analysis code, and stopping rule before
   observing outputs.
